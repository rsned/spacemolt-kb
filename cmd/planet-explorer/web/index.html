Help / Parameter reference

Render flow (with ControlConfig + Splines)

  1. Generate 5 fBm control fields (Continentalness, Erosion, PeaksValleys, Temperature, Humidity).
  2. Each field's Spline maps its [0, Amp] output to a height contribution.
  3. Sum spline outputs → normalize to [0,1] heightmap.
  4. Apply craters, then color the surface.
  5. If BiomeTable set: lookup color from (Temperature, Humidity, height) with bilinear OkLab blend.
  6. Apply ocean / snow / polar-cap overlays.
  7. Domain warp (if Amp>0) displaces sphere coords before sampling — produces swirly, non-axis-aligned features.

fBm parameters (per field)

  • Amp — output multiplier on top of [0,1] noise. Spline Input runs [0, Amp]. Typical 1.0.
  • Freq — base spatial frequency. 1.0 ≈ one period across the planet. Higher = smaller features. Useful 0.5–8.
  • Octaves — stacked noise layers. More = more detail (and compute). Typical 3–5.
  • Lacunarity — frequency multiplier per octave. Standard fBm = 2.0.
  • Persistence — amplitude decay per octave. Standard fBm = 0.5. Higher = noisier output.

Field semantics

  • Continentalness — macro land/ocean. Steep mid-section in the spline = sharp coastlines.
  • Erosion — smooths highlands. Spline output usually negative (subtracts from height).
  • PeaksValleys — small-scale mountain roughness on top of macro shape.
  • Temperature — biome row index. Combined with cos(latitude) so poles read colder.
  • Humidity — biome column index. No latitude bias.

Knots format

Fritsch-Carlson monotone cubic spline. Sorted by Input ascending. Out-of-range Inputs are clamped to nearest knot's Output.

[{"Input":0,"Output":0},{"Input":0.4,"Output":0.05},{"Input":1,"Output":0.6}]

Tuning loop

  1. Pick a type — profile JSON loads.
  2. Edit any sub-panel; click Reset to zero its noise params.
  3. Click Regenerate to render at the selected face size.
  4. Hover any field/parameter row for an inline reminder.
  5. Click Export JSON to copy the tuned profile to the clipboard.

The new pipeline only activates when…

Render uses the new control-fields path only when both: (a) at least one ControlField has non-zero Amp/Freq/etc., AND (b) at least one Spline has a non-empty Knots array. Otherwise it falls back to the legacy single-fBM heightmap.
