Relay Station

Security 0 Lawless

Relay Station is the lane name for what the old charts call Ross Major, and the older name is still stamped on every body in the system. A white dwarf lights it thinly, and the Collective's interest in neighbouring The Archive reaches this far as little more than the odd Voidborn hull passing through. Whatever the lane name once meant, the charts no longer say.
