Lore
The Chop Shop ships with a shield booster and a fitting budget that dwarfs every other salvager on the market. Patchwork engineers figure every salvage job is different — some need weapons, some need cargo expansion, some need speed — so they built a hull that handles all of them depending on what the pilot bolts on before launch. The best tow bonus in its class comes standard, because towing is the one thing every salvage run needs. The name was supposed to be temporary. The crews voted to keep it. Station authorities pretend not to notice that some Chop Shops return from "salvage runs" with suspiciously fresh debris.
