    How is the starting recipe chosen?

    When several recipes make the same item, one is preselected. Each rule below is skipped if it would rule out every remaining option:

    1. Packaging recipes (wrap_… / unwrap_…) are never used — they only put an item in a container and take it out again.
    2. Recipes calling for salvage are set aside.
    3. Recipes are preferred whose ingredients are all mined, or craftable from mined ingredients. This avoids starting you on a path that depends on wildlife drops, mission rewards, or anything else no recipe produces.
    4. Of what remains, the recipe producing the most per batch wins.
    5. An exact tie is broken by recipe name, alphabetically.

    Ingredient cost is not considered — only batch size. And where every recipe needs a drop, one is picked anyway: some items genuinely cannot be made from mined materials alone.

    These are only starting points. Use the dropdown on any box to choose a different recipe; your choices are kept in the page address, so you can share or bookmark a particular breakdown.
