Build cost by station

Savings = the finished item's cheapest ask at that station − build cost (positive = building beats buying it outright). Profit = the station's best bid for the finished item − build cost (positive = build-and-sell arbitrage). Both use the BoM cost and appear only when that build is feasible. Ships have an ask but no bid, so they show Savings only. @0 is local; +1/+2/+3 pool inputs from stations within that many jumps (cheapest sourcing). When a build can't complete, the cell shows how many of its inputs are sourceable within that radius (e.g. 11/16); an em-dash means the station has no market there or the mode does not apply.
